# 🚦 Traffic Light Simulator

---

## 🇬🇧 English

### Description
A simple interactive Traffic Light Simulator built with pure HTML, CSS, and JavaScript. It features a rainbow blinking title and a button to manually switch the traffic light through its states.

### Features
- 🔴 Red, 🟡 Yellow, 🟢 Green light simulation
- Smooth light transition with a yellow warning phase before switching
- "Switch Traffic Light" button to manually control the lights
- Button is temporarily disabled during transition to prevent spam clicks
- 🌈 Rainbow blinking "TRAFFIC LIGHT SIMULATOR" heading

### How to Use
1. Open `index.html` in any web browser
2. The light starts on **Red**
3. Click the **"Switch Traffic Light"** button
4. The light briefly turns **Yellow**, then switches to **Green**
5. Click again to go back through **Yellow** → **Red**

### Project Structure
```
revou-coding-camp-traffic-light/
├── index.html      # Main HTML page with styles
├── app.js          # JavaScript logic for light switching
└── README.md       # Project documentation
```

### Technologies Used
- HTML5
- CSS3 (animations, flexbox)
- Vanilla JavaScript (DOM manipulation, setTimeout)

### Live Preview
Open `index.html` directly in your browser — no server or installation needed.

## 🇮🇩 Bahasa Indonesia

### Deskripsi
Simulator Lampu Lalu Lintas interaktif yang dibuat menggunakan HTML, CSS, dan JavaScript murni. Dilengkapi dengan judul berwarna pelangi yang berkedip dan tombol untuk mengganti lampu secara manual.

### Fitur
- 🔴 Simulasi lampu Merah, 🟡 Kuning, 🟢 Hijau
- Transisi lampu yang halus dengan fase kuning sebelum berganti
- Tombol "Switch Traffic Light" untuk mengontrol lampu secara manual
- Tombol dinonaktifkan sementara saat transisi berlangsung
- 🌈 Judul "TRAFFIC LIGHT SIMULATOR" dengan efek kedip warna pelangi

### Cara Penggunaan
1. Buka file `index.html` di browser manapun
2. Lampu dimulai dari posisi **Merah**
3. Klik tombol **"Switch Traffic Light"**
4. Lampu sebentar menyala **Kuning**, lalu berganti ke **Hijau**
5. Klik lagi untuk kembali melalui **Kuning** → **Merah**
